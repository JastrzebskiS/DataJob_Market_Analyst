# DataJob_MarketA_Analyst


# 📊 Data Job Market Analysis

## 📌 Project Overview

This project analyzes global developer salary trends using real-world survey data.

The goal is to identify which factors (skills, experience, location) have the biggest impact on compensation in the tech industry.

---

## 🏗️ Architecture

Data pipeline:
Kaggle dataset → Airflow (ETL) → PostgreSQL (Data Warehouse) → Superset (Dashboard)

---

## 🛠️ Tech Stack

* Apache Airflow
* PostgreSQL
* Apache Superset
* Docker

---

## 📂 Project Structure

* airflow/ → DAGs
* scripts/ → data processing
* data/ → raw datasets
* sql/ → queries and schema
